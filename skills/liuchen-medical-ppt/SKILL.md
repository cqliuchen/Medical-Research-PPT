# 刘晨医学科研 PPT 工作流

将论文、旧课件、脚本与批注整理成临床医生听得懂、证据可追溯、图像清晰且便于修改的汇报。只加载当前阶段需要的技能和参考文件。用户本次要求优先于以下默认偏好；历史日期、页数、删页和时限不自动延续到新项目。

团队使用时以当前讲者的姓名、角色与真实素材为准：刘晨的风格可以复用，第一人称经历、署名身份和论文归属不得套给其他成员。首次安装后按需运行`scripts/check_dependencies.py --mode build`或对应模式；该脚本只检测技能文件，服务配置仍按专用技能核验。缺少专用制作技能时，可先完成内容规划与逐页审阅，最终制作需补齐相关能力。

## 一、先识别任务与当前依据

读取用户最新指定文件，检查已有大纲、样张和批准意见。Word同时读取正文、表格、修订和批注，PPT同时读取实际页面及备注。版本冲突要记录差异，不能仅凭文件名“最终版”判断。

用简短更新说明依据、受众、任务类型和交付物；沿用已确认决策。默认保留**逐页提问审阅**：先准备具体文字与素材方案，再请用户决定，按[逐页提问](references/page-interview.md)执行。事实检索、普通排版和已确认事项不重复提问。

## 二、组合技能的路由

从本机当前技能目录定位并阅读实际`SKILL.md`，不固定插件版本目录。调用的技能各自负责工具契约，本技能负责组合、个人风格和范围控制。

**开始项目时先读[完整技能清单与调用链](references/skill-catalog.md)**，明确本次启用的技能、顺序与产物。此组合技能负责按需加载下列已安装技能，不复制或替代它们的实现。用户不必逐个重新指定名称。清单内“可选补充”仅在任务需要时启用，不将全部技能无差别运行一遍。

| 任务 | 组合方式 |
|---|---|
| 查文献、作者角色、DOI与全文 | `academic-search`主检索；深度综述/证据综合用`academic-research-suite`；`pdf`读全文、图注与原图；大批论文需要持久知识包时可用`paper2skill` |
| 互联网、网页和平台资料 | `agent-reach`获取；围绕具体问题整理高可信来源可加`research`；浏览器操作遵循`computer-use`或当前浏览器工具，不能以搜索摘要代替原文 |
| 论文与旧课件整合、新建或重排 | `presentations`读取与组装；需要论文时用`academic-search`；内容规则见[证据与叙事](references/content-evidence.md) |
| 逐页内容、版面与批注审阅 | `grill-me`→`grilling`；需要同步术语与决策文档时用`grill-with-docs`→`grilling`＋`domain-modeling`；需要他人补充实验信息时用`to-questionnaire`。具体分工见[逐页提问](references/page-interview.md) |
| 用户选择GPT Image生成 | 读取`codex-ppt`并执行适用流程；真实科研原图与视频在最终PPT独立嵌入，采用下述模式区分 |
| 单独概念图、背景或示意插图 | `imagegen`负责生成/编辑图像；与`codex-ppt`的整页生成区分；科研数据原图不交生成模型重画 |
| 图片版改成对象级可编辑 | `image-to-editable-ppt`重建指定页，`presentations`合并和核验保留页；见[制作与验收](references/production-qa.md) |
| 精简、局部换页、统一风格 | `presentations`，先建立旧新页码映射，只重建必要页 |
| 逐页Word大纲、脚本及修订模式 | `documents`处理正文、批注与真实修订；`presentations`同步备注；使用[逐页记录](references/page-record.md) |
| 演讲稿打磨 | 对照实际页面改备注；确需学术语言润色时加`academic-humanizer`，无需每页重复加载 |
| 去除机械表达、匹配个人口吻 | 按目标用`humanizer`、`write-like-me`；保留事实、数字与科学证据含义 |
| Markdown原稿、网页讲演或模板沉淀 | 仅需要时用`markdown-ppt-toolkit`；明确保存可复用模板时用`template-creator`，不替代精确PPT对象编辑 |

专门学术检索优先`academic-search`；普通网页、平台内容按需用`agent-reach`。技能缺失时说明受影响步骤，能按已读流程执行的部分照常继续，不虚构技能工具或验证结果。

### 生成模式

- **原生模式，默认**：文本、主要线条、表格、色块为原生对象；科研图、照片、背景与图标独立分层。
- **混合模式**：GPT Image提供背景、概念图或版式参考；主要文字与形状原生编辑，科研图与视频直接嵌入。需要原图不变或高自由度编辑时优先此模式。
- **整页图像模式**：用户接受文字不可分别编辑、且不存在必须直接嵌入的真实数据图时，按`codex-ppt`标准流程制作。其标准流程若与原图保护冲突，明确转为混合模式，不能声称标准整页流程已完成。
- **重建模式**：既有图片版页面需编辑时进入`image-to-editable-ppt`。科研图本身保留原图对象，图外文字和主要形状还原原生对象。

不为使用所有技能而先将原生稿栅格化再OCR；不把整页截图叠字称为高自由度可编辑。

## 三、默认个人工作风格

- **受众与表达**：默认面向神经内科及相关临床医生，以刘晨大夫第一人称专业口述。解释影像术语，强调临床观察、具体研究结果与用途。人文内容来自真实材料，不编造个人经历或病例。
- **逻辑**：临床问题→必要方法→具体发现→临床解释。影像汇报可沿结构→功能/网络→代谢→干预推进，根据本次研究调整，避免按论文逐篇平铺。
- **视觉**：继承最新批准样张；缺少样张时用16:9、深蓝标题栏、白底、金色强调、大字号、图为主。默认去除右上角医院Logo；本次明确保留时服从要求。
- **科研图**：MRI、电镜、病理、统计图及坐标数据保持原始；复杂图用完整原图加必要局部放大，保留图例、比例尺、色标和统计标注。
- **结论**：每页具体写出部位/连接/指标、比较对象、变化方向及表型关联。用积极、准确的结果表述，减少泛化与无必要的否定句；重要的不显著结果、设计边界及不确定性如实保留，不能改成阳性或因果结论。
- **上屏与出处**：去掉“原课件”“底部总结”“制作提示”等内部话语。主要文献在右下方白底区靠右排列，按需要列第一作者、通讯作者、年份、已核实年度IF及DOI；通讯作者中的**Chen Liu**加粗。无已确认SCI出处时文献区留白，不用近似论文填空。
- **视频**：保留实际可播放视频。仅跟踪遮挡人脸，躯干、四肢与足部保持可观察；治疗前后配对并列，正面与侧面需要放大时拆页。
- **备注**：逐页讲清看哪里、比较什么、核心发现和下一页衔接，直接可念，不照读术语。默认只写刘晨表达内容，主持问答须用户要求。

## 四、工作顺序与完成标志

1. **盘点**：提取范围内每页文字、备注、分组对象、原图、视频与来源；图片页实际渲染阅读。
2. **组织**：按临床问题合并重复研究，保留独有发现，建立旧页→新页、素材→新页映射，落实用户批注。
3. **逐页准备与提问**：每页先给标题、全部上屏文字、确切结论、原图/图号、布局和讲稿重点。按依赖关系分轮审阅；未确认的内容不进入最终生成，已确认页可在依赖条件满足后推进。用户明确说不用提问或直接执行时调整本次模式。
4. **制作**：沿用批准样张，局部修改不重新选择整套风格；新风格和用户要求的样张先确认。按所用专用技能记录真实生成/重建状态。
5. **核验**：逐条检查修改、证据、所有修改页渲染、备注和媒体；完整新稿逐页检查。另存新版，保留原文件。见[制作与验收](references/production-qa.md)。

用户只要求文字Word审阅版时止于该交付；审阅确认后再生成PPT。不得因已有生成能力越过本次交付范围。

## 五、成本与续作

逐页提问保留，但同一轮可集中提出互不依赖的问题；每题对应真实页和具体选择，不轮番运行多个提问技能。已回答的决策记录后复用，只在新证据改变前提时重开。

用户指定medium等推理强度时，仅通过实际支持的工具参数设置，不声称能改变整个会话设置。复用已批准文字、图像、OCR及已通过页面，局部失败只修局部。专用技能要求页面工作者时按其派发与状态规则执行，其他任务不默认多代理。

长任务在项目`续作说明.md`记录输入版本、页映射、已通过/运行中/待修页、当前CLI状态位置、验证证据与下一步，避免重复派发。只在用户要求时创建真实自动化；不能保证预留精确token比例或未来配额。遇限制先保存可恢复进度。

仅处理当前授权材料；此技能不授权发送邮件、投稿或传播病例信息。交付报告页数、可编辑范围、保留内容、实际核验及仍需决定的具体事项。
