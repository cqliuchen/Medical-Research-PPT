# 逐页图文审阅记录

复杂课件与Word大纲使用；单页改字按需简化。

## 项目头

当前源文件/版本；受众与目的；本次页数/时长；必留与排除范围；批准样张；生成模式；交付物与审阅阶段。

## 每页条目

| 字段 | 内容 |
|---|---|
| 稳定页ID、新页码、旧页码 | 重排后可追踪 |
| 章节/临床问题 | 本页为何在此 |
| 最终标题与全部上屏文字 | 正文、分组、图注、确切结论、文献；不混入制作提示 |
| 主要证据 | 研究ID、设计、最终样本、比较与结果，按实际需要 |
| 原图素材 | 文件、原PPT页、图号/面板，完整图及局部放大关系 |
| 布局 | 主次、左右/上下、重点与对象分层 |
| 演讲稿 | 看图指向、核心结果、临床解释与过渡 |
| 讲解级别与估时 | 精讲/快速，含视频时间 |
| 提问与审阅状态 | 本页问题、用户决定或沿用批准依据 |

无图片文字大纲只列素材路径/图号；图文大纲嵌缩略图。全部上屏文字要完整，不以“大意如下”替代。

项目按需保存旧新页码及独有素材覆盖表、证据表、`逐页决策.md`和`续作说明.md`。制作提示与待核实项留在工作记录；必要的科学不确定性仍如实表达。
