# 制作与验收

## 分层与科研原图

标题、正文、文献、主要线条、表格和色块用原生对象，图标与背景独立。科研图内部原始标签保留在图中，不为“所有文字可编辑”破坏数据原图。保留原始媒体字节，等比例缩放；裁切只处理空边，局部放大同时保留完整图。

混合模式让生成模型负责背景、概念示意或版式参考；MRI、电镜、病理、散点、误差棒和真实轨迹直接嵌入，不让模型重绘。正文可从24—28pt、标题30—36pt起，结合样张与投影调节；主图有足够空间，不靠密集小字保留内容。

对象级重建遵守`image-to-editable-ppt`当前prepare、dispatch、record、finalize与OCR流程。检查已有OCR配置，必要时按其要求询问；不把历史“已配置”当成当前服务可用的证据。不手写CLI状态跳过验证。

## 复制与换页

冻结源页码，先写替换/插入映射，一次组装，避免页码偏移。局部修改保留非目标页、备注、媒体、动画与超链接；若当前工具无法保留某项，先确定具体影响并选择适当路径。

复制分组对象注意深层组合、墨迹/contentPart、图片占位符继承几何、母版和主题、隐藏在背景的Logo、媒体关系及Content Types扩展名大小写。原课件占位符图跨版式复制后可能漏图，要实际渲染核对。

## 病例视频

确认内嵌/链接、时长、封面、播放关系。仅对人脸跟踪遮挡，检查起止、转头、俯身和出入画面；颈以下与四肢不遮。旧视频肢体已经被马赛克烘焙覆盖时，应找未遮挡原视频重新处理，不能还原不存在的真实数据。

治疗前后同方向、同尺度并列，正侧面分别配对；保留实际可播放视频，不用截图替代。

## 原生渲染

Windows可用隐藏PowerPoint自动化打开、导出。LibreOffice用本机`C:\Program Files\LibreOffice\program\soffice.exe`，不因运行时未内置就宣布无法渲染，不例行执行`--version`。Word按`documents`要求渲染检查。

## 验收依据

| 范围 | 通过条件 |
|---|---|
| 文件 | 实际原生打开，无修复提示；ZIP有效只作结构补充 |
| 页序 | 页数、替换插入删除与映射一致 |
| 可编辑 | 指定页主要文字和形状原生，原图/图标/背景分层，非整页截图叠字 |
| 视觉 | 所有修改页逐页渲染，无漏图、溢出、拉伸、遮挡，科研坐标和图例可辨；完整新稿检查全稿 |
| 原图 | 必留媒体哈希一致；授权的视频脱敏单独记录变换 |
| 备注 | 保留时内容一致；重写时与当前画面、组别、新页序一致 |
| 视频 | 关系完整、时长与封面正确，实际播放抽查，遮脸保肢体 |
| 非目标页 | 适用时比对页内容/关系或渲染，不只看总页数 |

仅修具体失败，不重新生成已合格资产。交付给出简短文件链接、页数、修改范围、实际可编辑程度及具体未解决项；原图内部仍是位图要如实说明。
